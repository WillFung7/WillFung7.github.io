# Hénon Map

The Hénon Map is a simplified model of a ring, consisting only of a linear one turn map and a localized nonlinearity, usually a thin sextupole kick. It is the simplest nonlinear map for a ring. For the 1D case, the Hénon Map is expressed as:

$$\begin{aligned}
\bar{p}_n = p_n - q_n^2 \\
q_{n + 1} = q_n\cos(\mu) + \bar{p}_n\sin(\mu) \\
p_{n + 1} =-q_n\sin(\mu) + \bar{p}_n\cos(\mu)
\end{aligned}$$

As the equations show, a thin 1D sextupole kick is followed by a linear transport matrix. The map has only one parameter: the phase advance or indirectly the tune $$\mu = 2\pi\nu$$. Tunes near the resonances will yield higher nonlinearity, demonstrating less stable trajectories. This tracking is done for a specified amount of turns if the particle is within a stable orbit, or as many turns as the particle stays bounded if it is in a chaotic region. The Hénon Map is usually used as a toy model to study resonance islands, tune shifts, chaotic regions, and dynamic aperture. 

For a 2D Hénon Map, it is expressed in a similar way:

$$\begin{aligned}
\bar{p}_{x, n} = p_{x, n} + x_n^2 - y_n^2 \\
\bar{p}_{y, n} = p_{y, n} - 2x_ny_n \\
x_{n + 1} = x_n\cos(\mu) + \bar{p}_{x, n}\sin(\mu) \\
y_{n + 1} = y_n\cos(\mu) + \bar{p}_{y, n}\sin(\mu) \\
p_{x, n + 1} =-x_n\sin(\mu) + \bar{p}_{x, n}\cos(\mu) \\
p_{y, n + 1} =-y_n\sin(\mu) + \bar{p}_{y, n}\cos(\mu)
\end{aligned}$$

The 2D model is used to study everything else as well as diffusion, or the interplay between the transverse planes.
