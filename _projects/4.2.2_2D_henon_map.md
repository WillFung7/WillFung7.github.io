# 2D Hénon Map

This is an interactive demo of the 2D Hénon Map. The first plot is a dynamic aperture (DA) scan based on the user specified working point ($$\nu_x, \nu_y$$). The user can also specify the number of turns $$N_{turns}$$ the particle trajectory goes through phase space. Given a number of turns, if the trajectory goes beyond $$r_{max}$$, the trajectory is considered "lost". The blue boundary denotes a rough (not exact) maximum DA a trajectory can survive without reaching $$r_{max}$$ given $$N_{turns}$$. The DA is calculated using a bisection search. The boundary points input denotes how rough the boundary is and the tolerance input denotes the accuracy of the bisection search to calculate the DA.

After the DA area is calculated, the user can then specify the maximum x and y values that will be used in plotting the 4D Phase Space in the next plot. It is recommended to chose points that stay within the DA, and the $$x_{bound}, y_{bound}$$ text (denoted as red dots in the figure) are guides to help the user select $$x, y$$. 

The bottom figure shows then the 4D Phase Space plot corresponding to the user specified inputs before as well as the number of trajectories as well.
